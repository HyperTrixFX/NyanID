# QQ 机器人（Qbot）

项目内置一个 QQ 机器人，通过 `io.github.kloping.qqbot` 框架接入 QQ，可用于在 QQ 里查看服务器状态、在线玩家、发全服广播、以及和 AI 聊天。

## 配置

在 `config/application.yml` 的 `NyanidSetting.Qbot` 下：

```yaml
NyanidSetting:
  Qbot:
    isEnable: false       # 是否启用 QQ 机器人
    appid: "..."          # 机器人 appid
    secret: "..."         # 机器人密钥
```

`isEnable=false` 时启动日志会提示「Qbot已在配置文件中被关闭」。

## 工作原理

1. `QbotServices.initQbot()`（`@PostConstruct`）在启用时创建 `Starter` 并注册 `ListenerHost`。
2. 好友消息 / 群消息通过 `@EventReceiver` 监听，转成内部事件 `QbotFriendMessageReceivedEvent` / `QbotGroupMessageReceivedEvent`，`postAsync` 到内部 `EventBus`。
3. `QbotListener` 监听这两个事件，解析消息内容并分发命令。

## 支持的命令（好友 / 群通用）

| 命令 | 说明 |
| --- | --- |
| `/help` | 返回 Markdown + 测试键盘（示例） |
| `/status` | 查询各子服务器在线状态与人数 |
| `/list` | 查询在线玩家列表 |
| `/nyanid` | 返回 `awa` |
| `/bc <消息>` | 全服广播（返回送达人数） |
| `d` | 返回 `1`（示例） |
| 其它 | 交给 `AIServices.chat` 作为 AI 聊天处理 |

## 相关类

| 类 | 职责 |
| --- | --- |
| `services/QbotServices` | 初始化 QQ Starter、注册消息监听 |
| `eventbus/listener/QbotListener` | 处理好友/群消息命令 |
| `eventbus/SysEvent/QbotFriendMessageReceivedEvent` | 好友消息事件 |
| `eventbus/SysEvent/QbotGroupMessageReceivedEvent` | 群消息事件 |
