# 环境搭建与部署

## 依赖

- JDK 21
- MySQL（数据库连接见 `config/application.yml`）
- Redis（用于登录会话、serverId 校验、站内通知等）
- Maven（项目使用 `pom.xml`，Spring Boot 4.1.1）

## 构建

```bash
# 打包
mvn clean package -DskipTests

# 运行
java -jar target/NyanID-*.jar
```

> 项目未配置 `mvn` 时，也可在 IDE（IDEA 等）中直接运行 `NyanIdApplication`。

## 目录结构（运行期）

首次启动会在运行目录创建 / 校验以下目录：

```
config/                       # 配置文件（application.yml 等）
Data/
├── UserAvatar/               # 用户头像
├── GIFAvatar/                # GIF 头像
├── UserData/                 # 用户数据
└── YggdrasilTexture/         # 皮肤 / 披风纹理（hash-* 文件）
plugins/                      # 插件目录
```

## 配置文件

| 文件 | 作用 |
| --- | --- |
| `config/application.yml` | 主配置：数据源、Redis、邮件、端口、`NyanidSetting.*`、`yggdrasil.*`、`ai.*` |
| `src/main/resources/application.properties` | Spring 基础配置（日志、JPA、Tomcat 等） |
| `SystemConfig`（数据库表） | 动态配置键值（`proxy.*`），见 [03-配置参考](./03-配置参考.md) |

> 启动时若 `config/application.yml` 不存在，会从 classpath 的 `application.cfg` 复制一份；`Permissions.yml` 同理。

## 启动流程

1. 校验并创建运行目录。
2. `SystemConfigCacheService.loadConfigs()` 加载 `SystemConfig` 表到内存缓存。
3. 若 `NyanidSetting.EnableCommand=true`，启动控制台命令线程（`/help` 查看）。
4. 若 `NyanidSetting.EnableProxy=true`，启动 Netty 代理监听 `proxy.port`。
5. `BanExpiryScheduler` 每 60 秒批量清理过期封禁。

## 关键开关（application.yml → NyanidSetting）

| 配置 | 说明 |
| --- | --- |
| `EnableProxy` | 是否启动 Minecraft 代理 |
| `EnableCommand` | 是否启用控制台命令 |
| `EnableUserRegister` | 是否允许注册 |
| `allowedOriginPatterns` | CORS 允许的来源 |
| `MAX_REQUESTS_PER_SECOND` / `TIME_FRAME_IN_MILLISECONDS` | authserver IP 限流 |
| `TurnstileSecretKey` / `TurnstileSecretSiteKey` | Cloudflare Turnstile 验证 |
| `HOST` | 前端域名（用于注册邮件链接） |
| `ContactEmail` / `TeamName` | 站点信息 |
