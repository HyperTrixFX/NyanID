# 控制台命令

控制台命令在 `NyanidSetting.EnableCommand=true` 时启用，运行在独立线程，读取标准输入。

| 命令 | 说明 |
| --- | --- |
| `/help` | 列出所有已注册命令及其说明 |
| `/stop` | 5 秒后关闭 Spring Boot |
| `rc` | 刷新配置文件（重载 `SystemConfig` 缓存） |
| `hello` | 示例命令（无实际输出） |
| `/op` | 授予某个 uid 根权限（root） |
| `/systemctl` | 系统管理（全站通知） |
| `/redis` | 操作 Redis |
| `/ac` | 账号管理（封禁等） |

## /help

列出 `CommandManager` 中所有命令的 `getName()` 与 `getDescription()`。

## /stop

```text
/stop
```

打印提示后延迟 5 秒执行 `System.exit(0)`。

## rc

```text
rc
```

调用 `SystemConfigCacheService.loadConfigs()` 重新加载配置缓存。修改 `SystemConfig`（`proxy.*`）后执行即可热生效。

## /op

```text
/op <uid>
```

给 `uid` 授予根权限 `*`（超级管理员），等价于 `PermissionService.grant(uid, "*")`。

## /systemctl

### 设置全站通知

```text
/systemctl alert <NotificationType> <NotificationData> <NotificationTypeName> <Time(秒)>
```

写入 Redis `ServerInfo`（带过期时间）。

> 早期版本曾有的 `adminpwd`（管理员权限）子命令已移除，授权改用 `/op <uid>`。

## /redis

```text
/redis set <key> <value>
/redis get <key>
/redis setTimeValue <key> <value> <秒>
/redis remove <key>
```

## /ac（账号管理）

```text
/ac ban <uid/email/username> [原因]
/ac unban <...>
/ac remove <...>
/ac create <email> <password> <username>
/ac change <...>
```

- `ban`：封禁账号（`Type=6` 死封），已封禁则跳过。
- 其余子命令部分实现（`remove` 等为空占位）。

## hello

```text
hello
```

无实际输出（示例）。
